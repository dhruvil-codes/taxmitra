The Income Tax Department's Rectification service provides Reprocess the Return, Tax Credit Mismatch Correction, and Return Data Correction (offline) request types. Reprocess is for true and correct return particulars that CPC did not consider. Tax Credit Mismatch Correction is for correcting TDS, TCS or tax/challan details already in the processed return using the Department's records. Return Data Correction is for correcting existing return data; it must not be used to declare a new income source or an additional deduction. A rectification request is for a mistake apparent from the record, not simply a disagreement with the processed result.

For TDS or TCS reporting errors, the employer, deductor or collector may need to file a correction statement. For taxpayer-entered tax or challan details, the taxpayer may use the applicable portal correction route only after checking Form 26AS and the return. Tax Mitra must not invent credit values or select an owner when the record is uncertain.
