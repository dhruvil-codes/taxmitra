7. What if I don't respond to a Defective Notice? If you fail to respond to the defective notice within stipulated period then your return may be treated as invalid and therefore consequences such as penalty, interest, non carry forward of losses, loss of specific exemptions may occur,as the case may be in accordance with the Income Tax Act. 8. I have been notified about defective returns u/s 139(9). Can I file the return again as fresh return for that assessment year? Yes, You can either file the return as a fresh/ revised return incase the time provided for filing the return in a particular assessment year has not lapsed or alternatively you can also choose to respond to Notice u/s139. However, once the time provided for filing the return for a particular assessment year has lapsed, you will not be able file the return as a fresh/ revised return and you will have to respond to Notice u/s 139(9).
